# اپ اندروید فروشگاه کلکسیون (clnshop.ir)

شامل دو بخش:

- `android/` : اپ اندروید (Kotlin). سایت را در یک WebView بومی نشان می‌دهد و امکانات اپ را اضافه می‌کند: نوتیفیکیشن Firebase (با تصویر)، اسپلش، کشیدن برای تازه‌سازی، صفحه آفلاین، دکمه برگشت، آپلود فایل، دانلود، باز شدن لینک‌های clnshop.ir داخل اپ، باز شدن شبکه‌های اجتماعی بیرون از اپ، و عبور درگاه پرداخت داخل خود اپ.
- `wordpress-plugin/clnshop-app-push/` : پلاگین وردپرس برای ثبت دستگاه‌ها و ارسال نوتیفیکیشن، همراه پنل مدیریت (منوی «اپ کلکسیون»).

## نوتیفیکیشن‌های خودکار
تغییر وضعیت سفارش (متن هر وضعیت قابل ویرایش)، محصول جدید، موجود شدن محصول، کوپن جدید و یادآوری سبد رهاشده. ارسال دستی از پنل و تاریخچه ارسال‌ها هم هست.

## راه‌اندازی

### ۱) Firebase
1. در [Firebase Console](https://console.firebase.google.com) یک پروژه بسازید.
2. یک اپ Android با Package name برابر `ir.clnshop.app` اضافه کنید و `google-services.json` را دانلود کنید.
3. در Project settings ← Service accounts روی Generate new private key بزنید (فایل JSON).

### ۲) پلاگین وردپرس
1. پوشه `wordpress-plugin/clnshop-app-push` را زیپ کنید و از افزونه‌ها ← افزودن ← بارگذاری نصب و فعال کنید.
2. منوی «اپ کلکسیون» ← «تنظیمات و رویدادها»: محتوای JSON مرحله ۱.۳ را بچسبانید و ذخیره کنید، سپس «تست اتصال» را بزنید.

### ۳) ساخت APK
در گیت‌هاب: Settings ← Secrets and variables ← Actions:

| Secret | توضیح |
|---|---|
| `GOOGLE_SERVICES_JSON` | کل محتوای فایل `google-services.json` (الزامی) |
| `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` | اختیاری، برای امضای اختصاصی (لازم برای انتشار در مارکت‌ها) |

بعد از Actions ← Build Android APK ← Run workflow، فایل APK در بخش Artifacts دانلود می‌شود. بدون کلید اختصاصی، APK با کلید دیباگ امضا می‌شود که برای نصب مستقیم کافی است.

## نکته
اتصال دستگاه به حساب کاربر: پلاگین وقتی صفحه‌ای داخل اپ باز می‌شود توکن دستگاه را به کاربر واردشده وصل می‌کند؛ نوتیفیکیشن وضعیت سفارش و سبد رهاشده فقط برای کاربرانی ارسال می‌شود که داخل اپ وارد حساب شده باشند.
